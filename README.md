# AI Telegram Bot для анализа отношений пары

Приложение — это Telegram-бот, который собирает описание двух партнеров и контекст их отношений, после чего формирует структурированный анализ с помощью OpenAI.

## Что умеет бот
- Запрашивает данные по шагам (партнер A, партнер B, контекст).
- Генерирует разбор отношений в формате:
  - ключевая динамика,
  - сильные стороны,
  - риски конфликтов,
  - план на 7 дней.
- Поддерживает сброс диалога командой `/reset`.

## Быстрый старт

1. Установите зависимости:
   ```bash
   npm install
   ```
2. Создайте `.env` из примера:
   ```bash
   cp .env.example .env
   ```
3. Заполните переменные в `.env`:
   - `TELEGRAM_BOT_TOKEN` — токен вашего Telegram-бота от @BotFather
   - `OPENAI_API_KEY` — API-ключ OpenAI
   - `OPENAI_MODEL` — модель (по умолчанию `gpt-4o-mini`)
4. Запустите бота:
   ```bash
   npm start
   ```

## Команды
- `/start` — начать сценарий анализа.
- `/reset` — сбросить текущие данные и начать заново.

## Структура проекта
- `bot.js` — логика Telegram-бота и сценарий общения.
- `relationshipAnalyzer.js` — модуль ИИ-анализа через OpenAI API.
- `.env.example` — пример переменных окружения.

## Важно
Бот не заменяет психотерапию или помощь профильных специалистов. Для кризисных случаев и угрозы безопасности нужно обращаться в экстренные службы и к профессионалам.
